# Spring Boot Swagger Test

A simple testing project to learn how to integrate and use Swagger (OpenAPI 3) for API documentation in a Spring Boot application.

##  Features
* Automated API documentation generation using Springdoc OpenAPI.
* Interactive Swagger UI web interface.

## 🛠 Prerequisites
* Java 21 or higher
*  Gradle

##  How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Savmeng/spring-boot-swagger-test.git
   ```
2. Navigate into the project folder:
   ```bash
   cd spring-boot-swagger-test
   ```
3. Run the Spring Boot application using your IDE or terminal.
